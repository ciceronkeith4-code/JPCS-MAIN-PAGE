# JPCS SSCR Manila Portal

This Vite React portal uses Supabase as its authentication and database backend for student academic records, curriculum management, and administration.

## Local development

1. Copy `.env.example` to `.env.local`.
2. Fill in `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
3. Run `npm install` and `npm run dev`.
4. Open `http://localhost:5173/login`.
